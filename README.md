# MBO Leads

Telegram-бот, що ловить нові замовлення для фрилансерів у публічних Telegram-каналах і миттєво надсилає їх підписникам за обраними категоріями.

Окремий проєкт, із Джарвісом не пов'язаний.

## Як працює

1. Кожні 3 хвилини бот читає публічні канали зі списку через веб-перегляд `t.me/s/<канал>`. Логін і API-ключ Telegram для цього не потрібні.
2. Нові пости пачками до 20 штук іде на розбір Claude: чи це замовлення, категорія, короткий заголовок і суть українською, бюджет, віддалено чи ні. Реклама послуг, курси, новини й шахрайство відсіюються.
3. Повтори одного замовлення з різних каналів прибираються: тексти порівнюються за словами.
4. Свіже замовлення (до 12 годин) отримують підписники його категорії. Безкоштовно — `FREE_DAILY_LIMIT` на день, Pro — без ліміту.
5. Картка замовлення містить заголовок, суть, бюджет, формат і посилання на оригінальний пост. Контакти замовника бот не копіює: людина відкриває оригінал.

Кнопки 👍 / 👎 / 🚩 під карткою збирають оцінки, а `/sources` показує, які канали дають корисні замовлення.

## Команди

**Користувачі:** `/start`, `/categories`, `/pause`, `/resume`, `/plan`, `/help`.

**Адміністратор** (`ADMIN_TELEGRAM_ID`):
- `/addsource @канал` — додати канал. Старі пости зберігаються, але не розсилаються.
- `/delsource @канал` — вимкнути канал.
- `/sources` — канали, скільки замовлень дали за 7 днів, оцінки, помилки.
- `/stats` — користувачі, замовлення, розсилка й витрати на розбір.
- `/pro <telegram id> <днів>` — видати Pro вручну, поки немає оплати; `0` забирає.

## Налаштування

Змінні середовища описані в `.env.example`. Секрети (токен бота, ключ Claude, пароль бази) задаються лише в налаштуваннях деплою.

- `LEADS_MODEL` — модель для розбору, за замовчуванням `claude-opus-5-5`. `claude-haiku-5-5` приблизно в 40 разів дешевша, варто порівняти якість на реальних постах.
- `MONTHLY_BUDGET_USD` — після цієї суми за місяць розбір зупиняється, а адміністратор отримує сповіщення.

## Деплой (Coolify)

1. **+ New → Postgres 16**, скопіювати внутрішню адресу в `DATABASE_URL`.
2. **+ New → Application** з цього репозиторію, Build Pack — Dockerfile, порт 3000, перевірка здоров'я `/health`.
3. Задати змінні середовища й запустити. Адміністратор отримає «🟢 Бот замовлень запущений».

Таблиці створюються самі при запуску.

## Розробка

npm install
npm run typecheck
